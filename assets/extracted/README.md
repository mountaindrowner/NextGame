# Extracted assets

Derived from creator-owned cattle-town art (`assets/reference/cattle-town/`,
see its PROVENANCE.md) via `npm run extract`. Same ownership applies.

- `objects-sheet/` — 62 cropped, transparent props (trees, cacti, rocks, hay,
  barrels, poles, windmill, water tower, barn, storefronts, fences, cattle).
- `terrain-tiles/` — island extraction of the terrain sheet (mixed: clean
  ~145px tiles + some merged road/field strips). Ground autotiles still want
  a grid-aligned source export or authored 32px tiles; objects are clean.

Showcase scale is ~4.5x (native tile ~32px). Downscale crops to taste.
