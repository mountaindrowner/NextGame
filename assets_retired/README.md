# Retired fighters

Not bundled into the game (`tools/build.py` only reads `assets/`). To bring a fighter back, move their files back
under `assets/` (same layout) and restore their entries in `src/game.js` from git history.

- **ivan/**: Ivan "The Bear" (Sambo grappler), removed in v1.24.0 when Keksan took his slot.
